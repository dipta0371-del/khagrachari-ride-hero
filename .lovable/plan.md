# নতুন রাইড এলে চালকের নোটিফিকেশন + APK-এর অবস্থা

## কেন এখন নোটিফিকেশন যায় না

তিনটি আলাদা কারণ, তিনটাই ঠিক করা দরকার:

1. **নতুন রাইড রিকোয়েস্টে কোনো নোটিফিকেশন পাঠানোই হয় না।** রাইড গ্রহণ, পৌঁছানো, যাত্রা শুরু, শেষ ও বাতিল — এগুলোর জন্য নোটিফিকেশন লেখা আছে, কিন্তু যাত্রী যখন রাইড চান তখন কাছের চালকদের কাউকে পাঠানো হয় না।
2. **কোনো ডিভাইস নিবন্ধিত নেই** — ডাটাবেসে ০টি ডিভাইস। নোটিফিকেশন পাঠানোর কোড শুধু মোবাইল অ্যাপে (APK) ডিভাইস নিবন্ধন করে; ব্রাউজারে কিছুই নিবন্ধন হয় না। তাই ওয়েবে এখন কোনো নোটিফিকেশন সম্ভব নয়।
3. ফায়ারবেস সংযোগ দেওয়া আছে, তাই সার্ভারের দিকটা প্রস্তুত — শুধু পাঠানোর জায়গা আর গ্রাহক (ডিভাইস) নেই।

## কী করব

### ১. নতুন রাইড এলে চালকদের জানানো
- যাত্রী রাইড নিশ্চিত করলেই যেসব চালক অনলাইন, অনুমোদিত, সেই যানের (বাইক/টমটম) এবং এই মুহূর্তে কোনো রাইডে নেই — তাঁদের সবাইকে "নতুন রাইড অনুরোধ · পিকআপ → গন্তব্য · ভাড়া ৳X" পাঠাব।
- একজন চালক রাইডটি নিয়ে নিলে বাকিদের "রাইডটি অন্য চালক নিয়েছেন" জানাব।

### ২. ওয়েবেও নোটিফিকেশন (APK ছাড়াই কাজ করবে)
- ব্রাউজারের জন্য ফায়ারবেস ওয়েব-পুশ যোগ করব: চালক প্যানেলে একটি বোতাম — "নোটিফিকেশন চালু করুন"। চাপ দিলে অনুমতি চাইবে, ডিভাইস নিবন্ধিত হবে।
- ব্রাউজার ট্যাব বন্ধ/মিনিমাইজ থাকলেও নোটিফিকেশন আসবে (সার্ভিস ওয়ার্কার দিয়ে)।
- Lovable প্রিভিউর ভেতরে ব্রাউজার অনুমতি চাইতে দেয় না — তখন "নতুন ট্যাবে খুলুন" বার্তা দেখাব।
- এর জন্য ফায়ারবেস সংযোগে **Include web push** অংশটি লাগবে (ওয়েব API key, App ID, VAPID key)। না থাকলে আমি সংযোগ হালনাগাদের কার্ড দেখাব — আপনাকে শুধু ফায়ারবেস কনসোল থেকে মানগুলো দিতে হবে।

### ৩. অ্যাপ খোলা থাকলে শব্দ/ব্যানার
- চালকের প্যানেল খোলা থাকা অবস্থায় নতুন অনুরোধ এলে একটি টোস্ট + বিপ সাউন্ড, যাতে পুশ ছাড়াও নজরে পড়ে।

### ৪. একটি ছোট বাগ
অ্যাডমিন নয় এমন কেউ অ্যাডমিন পাতায় গেলে "এই কাজের অনুমতি নেই।" এররটি লগে আসছে — এটিকে এরর না দেখিয়ে সরাসরি নিজের পাতায় ফেরত পাঠাব।

## APK কি এখন প্রস্তুত?

কোডের দিক থেকে প্রস্তুত (Capacitor, ব্যাকগ্রাউন্ড লোকেশন, পুশের কোড আছে), কিন্তু **APK ফাইলটা এখনো বানানো হয়নি** — Lovable-এর ভেতরে APK বিল্ড হয় না। বানাতে হবে এভাবে:

1. প্রজেক্ট GitHub-এ এক্সপোর্ট করুন
2. কম্পিউটারে `bun install`
3. ফায়ারবেস কনসোল থেকে `google-services.json` নামিয়ে `android/app/` ফোল্ডারে রাখুন (এটা ছাড়া অ্যাপে পুশ কাজ করবে না)
4. `bun run cap:android` → Android Studio খুলবে → Build → Build APK(s)

চাইলে GitHub-এ অটো-বিল্ড সেটআপ করে দিতে পারি, তখন কম্পিউটার ছাড়াই APK ডাউনলোড হবে — বললে প্ল্যানে যোগ করব।

## কারিগরি সংক্ষেপ

- `src/lib/rides.functions.ts`: `requestRide`-এ ম্যাচিং চালকদের বের করে `notifyUser` লুপ; `acceptRide`-এ বাকিদের "নেওয়া হয়ে গেছে" নোটিফিকেশন; `assertAdmin`-এর এরর পাথ ঠিক করা।
- নতুন `src/lib/push-web.ts` + `public/firebase-messaging-sw.js`: `VITE_LOVABLE_CONNECTOR_FIREBASE_MESSAGING_*` থেকে কনফিগ, `getToken` → `registerDeviceToken`; `messagingSenderId` App ID-এর দ্বিতীয় অংশ।
- `device_tokens` টেবিলে এখন `onConflict: "user_id"` — একজনের একাধিক ডিভাইস (ফোন + ব্রাউজার) রাখতে `(user_id, token)`-এ ইউনিক করে মাইগ্রেশন লাগবে; পুরনো/অচল টোকেন (FCM 404) মুছে ফেলা হবে।
- চালক প্যানেলে একটি নোটিফিকেশন-স্ট্যাটাস কার্ড (চালু/বন্ধ/নতুন ট্যাবে খুলুন/সেটআপ বাকি)।
