# নোটিফিকেশন শেষ করা — ওয়েব পুশের শেষ ধাপ

## কী কী হয়ে গেছে (আগের ধাপে)

- যাত্রী রাইড চাইলে কাছের ফাঁকা অনলাইন চালকদের পুশ যায়: "নতুন রাইড অনুরোধ · পিকআপ → গন্তব্য · ভাড়া"
- একজন চালক নিলে বাকিরা পান "রাইডটি নেওয়া হয়েছে"
- চালক প্যানেলে নোটিফিকেশন কার্ড + নতুন অনুরোধে টোস্ট ও বিপ সাউন্ড
- এক জন ব্যবহারকারীর একাধিক ডিভাইস (ফোন + ব্রাউজার) একসাথে রাখার ডাটাবেস পরিবর্তন
- অচল ডিভাইস-টোকেন নিজে নিজে মুছে যায়

## এখন যা বাকি

### ১. ওয়েব পুশের চাবি যোগ করা
আপনি App ID আর VAPID কী দিয়েছেন। ব্রাউজারে চালু করতে আরেকটা মান লাগবে: **Web API key** — Firebase Console → আপনার প্রজেক্ট → সেটিংস (গিয়ার আইকন) → General ট্যাবে "Web API key" লেখা জায়গায় থাকে।

তিনটা মানই গোপন কী নয় (Firebase ওয়েবের নিয়মে এগুলো পাবলিক), তাই আমি সরাসরি প্রজেক্টে বসিয়ে দেব — আপনার সংযোগ হালনাগাদ করা লাগবে না। এজন্য চাই:
- Web API key টা Firebase Console থেকে কপি করে চ্যাটে দিন

### ২. যাচাই
- চালক প্যানেলে "নোটিফিকেশন চালু করুন" বোতাম টেস্ট ব্রাউজারে চেপে ডিভাইস নিবন্ধিত হচ্ছে কিনা দেখব
- রাইড চাইলে সার্ভার থেকে নোটিফিকেশন পাঠানো হচ্ছে কিনা দেখব
- পুরো টাইপ-চেক ও দুই-পক্ষের রাইড টেস্ট আবার চালাব

### ৩. পাবলিশ
সব ঠিক থাকলে নতুন ভার্সন পাবলিশ করব, যাতে chtgari.com-এ নোটিফিকেশন কাজ করে।

## APK মনে করিয়ে

APK এখনো বানানো হয়নি — কোড প্রস্তুত। GitHub-এ এক্সপোর্ট → `bun install` → Firebase Console থেকে `google-services.json` নামিয়ে `android/app/`-এ রাখুন → `bun run cap:android` → Android Studio-তে Build → Build APK(s)।
